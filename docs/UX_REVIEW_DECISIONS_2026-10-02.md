# UX 리뷰 검토와 확정 기준

## 사용자 확정 사항

- 보관소 이름은 Archive로 통일한다. 보관소를 가리키는 “마스터”는 사용하지 않는다. 실제 콘솔 이름인 Master System은 이 규칙의 대상이 아니다.
- 온라인 스크랩과 다른 Collection/Archive에서 가져오기는 구분한다.
- 상세 패널의 요약 카드를 유지한다.
- 작은 글씨의 8~9px 혼용은 9px로 통일한다. 기존 본문·입력값까지 9px로 줄이지 않는다.
- 버전은 앱 이름 영역의 우측 아래에 더 작게 배치하고 앱 타이틀은 키운다.
- 기존 메뉴의 명칭과 순서를 먼저 다듬는다. 메뉴를 합치거나 하위 메뉴를 늘리는 일은 별도 판단한다.

## 외부 리뷰에 대한 반박 및 유보

1. **일부 지적은 이전 코드 기준이다.** 커밋 `7854117`에는 Slate 기본 테마, Pearl/Carbon/Sand/Aqua 이름, 한국어 내비게이션·설정 제목, 콘솔별 토글 장식 색 제거가 들어 있다. SYSTEMS/All Games 등과 SFC 토글 색 문제를 그대로 현재 문제로 취급하지 않는다.
2. **번역률 숫자는 재검증이 필요하다.** 1,002개 중 338개라는 집계는 대상 커밋·중복 제거·주석 제외·동적 문자열 처리·기존 패턴 번역 포함 여부를 확인하기 전에는 현재 번역률로 확정하지 않는다. 실제 언어 전환 화면과 누락 검사를 함께 사용한다.
3. **Storage를 모두 기기로 바꾸면 부정확하다.** 로컬 폴더와 네트워크 저장소도 포함한다. “내 목록/마스터/기기”라는 용어 체계를 자동 적용하지 않는다. Archive 명칭은 위 확정 사항을 따른다.
4. **스크랩과 가져오기를 합치지 않는다.** 온라인 서비스 조회와 보유 데이터 재사용은 출처와 동작이 다르다. 명칭으로 차이를 드러낸다.
5. **중복 정보가 있다는 이유로 요약 카드를 삭제하지 않는다.** 커버와 핵심 정보를 빠르게 확인하는 역할을 유지하고, 필요하면 카드 안의 중복 정보와 순서를 조정한다.
6. **작은 글씨를 일괄 11~12px로 올리지 않는다.** 정보 밀집도 요구와 충돌한다. 작은 라벨은 9px로 정리하고 본문·입력값은 기존 크기를 유지한다.
7. **모든 작업에 실행 취소 안내를 붙이지 않는다.** 실제로 복구 가능한 작업에만 표시한다. 삭제·이동·이름 변경별 지원 범위를 확인한다.
8. **저장된 필터를 구현하지 않는다.** 사용자가 앞서 제외했다. 첫 실행 위저드도 후순위이며 빈 화면의 짧은 다음 행동 안내를 먼저 개선한다.
9. **1000×640 겹침은 재현 후 판단한다.** 수평 스크롤을 사용하는 넓은 목록과 실제 컨트롤 겹침을 구분한다. 목업 Chromium 캡처를 WebView2 실사용 검증으로 대신하지 않는다.
10. **앱의 개성 부족은 제품 판단이다.** 기본 테마의 절제된 색을 기능 결함으로 취급하지 않는다. 시스템 배너는 이번 범위에서 제외한다.

## 수용한 후속 개선 방향

1. 한국어 UI의 용어와 남은 영어 혼용을 정리한다.
2. 새 문구부터 번역 키 ID와 변수 방식을 적용하고 번역 누락 검사를 도입한다. 기존 번역을 한 번에 전면 교체하지 않는다.
3. 좁은 창의 실제 겹침을 수정하고, 빈 Archive와 검색 결과 없음의 안내를 구분한다.
4. F1 단축키 도움말을 제공한다.
5. 대시보드의 누락 항목에서 해당 목록으로 이동하는 기능은 현재 연결 여부부터 확인한다.

위 후속 항목은 진행 방향이며 이 문서 작성 시점의 구현 완료 목록이 아니다.

## 이번 변경 검증

- 타이틀 18px, 버전 9px 우측 아래 배치와 작은 라벨 정리를 검증했다.
- 관련 UI 테스트 33개 통과. 너비 1000/1280px, 배율 100/130%의 4개 조합에서 타이틀·버전 영역 넘침과 겹침 검사를 통과했고 캡처를 확인했다.
- 전체 UI 테스트는 644개 중 643개 통과, 붙여넣기 하위 메뉴 테스트 1개 실패. 실패한 테스트의 단독 5회 반복은 모두 통과했으나 전체 실행 실패의 원인은 확정하지 못했다. 전체 통과로 기록하지 않는다.
- app.js 문법 검사와 git diff --check 통과.
- Chromium 목업 검증이며 실제 WebView2, NAS, ScreenScraper 서비스 동작 검증은 아니다.

### 메뉴 이벤트 후속 검증

- 앞서 실패한 하위 메뉴 테스트는 4개 워커로 30회 반복해 모두 통과했다. 원래 실패의 직접 원인은 확정하지 않았다.
- 별도 재현: 같은 이벤트 작업 안에서 메뉴 열기 → Escape → 다시 열기를 수행하면, 이전 메뉴가 예약했던 mousedown 등록이 뒤늦게 실행된다. 새 메뉴 안을 눌러도 이전 핸들러가 바깥 클릭으로 판단해 새 메뉴를 닫았다. 추가 테스트는 수정 전 실패했다.
- 메뉴 정리 시 예약된 등록 타이머도 취소하도록 수정했다. 복사·붙여넣기 테스트 23개 통과, 전체 UI 회귀 테스트 645개 통과(3.5분).
- 이 재현으로 확인된 결함과 앞선 간헐 실패가 같은 원인이라고 단정하지 않는다.

## 번역 구조와 안내 후속 구현

- `i18n-messages.js`에 한국어/영어 UI 메시지 195개를 ID와 변수 형태로 등록했다. ID 누락과 필수 변수 누락은 오류로 처리한다. 기존 문장 기반 번역표는 점진적 이전을 위해 유지한다.
- 메인·상세·우클릭 메뉴·대시보드·설정 9개 섹션의 문구와 툴팁, 드롭다운 항목을 정리했다. 온라인 검색과 다른 목록에서 가져오기는 별도 명령으로 유지한다. 게임 데이터는 번역하지 않도록 별도 표시한다.
- Archive 경로 예시의 백슬래시, 설명 입력창 안내, 빈 Archive의 복사/붙여넣기 안내를 추가했다. 필터 결과가 없는 경우와 빈 Archive 안내를 구분한다.
- F1 도움말을 작은 별도 모듈로 추가했다. 설정이나 작업 창이 이미 열려 있으면 F1이 그 창을 교체하지 않는다. 기존 모달·버튼 스타일을 사용한다.
- 빌드 전에 메시지 ID/한국어·영어/변수 검증과 실제 렌더링된 화면의 번역 검사를 실행한다. 실패하면 버전과 기존 빌드 출력을 변경하지 않는다. 빌드 환경에 Node.js, npm 의존성, Playwright Chromium이 필요하다.
- 기존 테스트는 번역된 라벨에 맞춰 기대값만 갱신했고 동작 검증을 유지했다. 새 검사에는 언어 전환, 변수, 미등록 ID, 사용자 텍스트 보존, 드롭다운, 빈 Archive, F1이 포함된다.

### 검증 범위와 남은 항목

- 한국어/영어 렌더링 검사를 필수로 연결했다. 일본어·스페인어·프랑스어는 제거하지 않았으나 완전 번역으로 판정하지 않는다. 새 ID에서 해당 번역이 없으면 영어로 표시한다.
- 화면 검사는 Chromium 목업 기준이다. 실제 WebView2 글꼴, 실서비스 오류 응답, 모든 충돌·복구 화면 및 모든 데이터 조합을 검증한 것은 아니다. 전체 문구를 ID로 전환한 것도 아니다.
- 요약 카드, Archive 명칭, 분리된 스크랩/가져오기, 9px 작은 라벨 기준은 유지한다. 전체 프론트엔드 교체나 대규모 파일 분리는 이번 번역 수정과 함께 진행하지 않는다.
- 백업 보관 기본값이나 Archive 저널 성능에 대한 외부 지적은 이 UI 작업에서 확인·변경한 항목으로 기록하지 않는다.

### 후속 구현 검증 결과

- 전체 UI 회귀 660개 통과(3.7분). 라벨 변경으로 실패한 기존 테스트를 수정하고 전체 실행을 완료했다.
- 이후 사용자 데이터 번역 방지를 목록/카드/상세/후보에 보완했다. 이 변경에 대한 UI 회귀 134개 통과(45.6초).
- 빌드 필수 번역 검사 18개 통과, Python 번역표/검사 도구 테스트 9개 통과. 메시지 132개의 한국어·영어와 변수 구성을 확인했다.
- F1 도움말과 영어 Scraper 설정 캡처를 확인했다. 실제 WebView2 앱 실행이나 설치본 빌드는 수행하지 않았다. 따라서 빌드 버전은 올리지 않았다.

### 최근 기능·설정의 동작 후 문구 보완

- 사용자의 추가 지적을 확인했다. 앞선 9개 설정 탭 검사는 기본 상태만 보았고, 스크랩 후보 창과 연결 테스트/DAT 가져오기 후 결과는 검사하지 않았다. 기본 탭 검사 통과를 전체 기능의 번역 완료로 해석하면 안 된다.
- 스크랩 제목·사용량·후보 수·버튼·확장 화면·근거와 검색 진행/중지/후보 없음 상태를 보완했다. 연결 성공/실패 접두 문구, 동시 요청 수, DAT 개수/가져오기 결과, Archive 폴더 검사와 DB 감지 결과도 번역한다.
- 직접 `textContent`/`title`에 넣는 결과 문구는 명시적으로 번역하도록 바꿨다. 사용자 제목·설명·파일명과 원본 오류의 상세 내용은 번역 문구와 구분한다.
- 필수 번역 검사를 23개로 확대했고 모두 통과했다. Python 검사 9개와 JS 문법 검사, diff 공백 검사도 통과했다. 실제 ScreenScraper 서버 및 WebView2 실사용 검증은 아니다.
- 일본어·스페인어·프랑스어의 완전 번역은 여전히 확인되지 않았다. 한국어/영어 화면의 검증 범위가 확대된 것이다.
- 전체 UI 회귀 665개 통과(3.7분). 이후 영어 버튼 문구를 고정 폭에 맞게 줄였으며, 번역 검사 23개에서 버튼의 텍스트 넘침까지 확인해 통과했다. 한국어 버튼 문구와 크기는 유지했다.

### 후속 번역 감사: 충돌·복구·오류 상태
- 즐겨찾기 추가/해제는 안정된 ID로 연결했다. 항목 수와 ROM 개수 라벨의 한국어 표시를 정리했다.
- 붙여넣기 충돌의 요약·버튼·확장 안내, 복구 기록의 상태·개수·닫기 확인·백업 삭제 문구를 번역했다. 비교 대상의 게임 제목·설명은 원문을 유지한다.
- 필수 렌더링 검사에 즐겨찾기 변경, 확장된 붙여넣기 충돌, 복구 실패와 닫기 확인, 계정 연결 실패 및 재시도 가능 상태, 한국어 항목 수를 추가했다.
- 검증: Chromium 목업 번역 검사 28개, Python 번역 검증 9개 통과. JavaScript 구문과 diff 공백 검사 통과. 전체 UI 회귀 및 실제 WebView2는 이번 후속 변경에서 실행하지 않았다.
- 외부 서비스·백엔드에서 전달된 임의의 오류 텍스트를 자동 번역하는 기능은 없다. 연결 오류 검사는 HTTP 401 응답에 대한 UI 안내를 확인하며, 모든 오류 메시지의 번역 완료를 의미하지 않는다.

### 백엔드 오류 표시 후속 개선
- 실제 bridge/API 및 ScreenScraper provider의 정적 오류 29종과 매개변수 오류 3종을 한국어·영어 카탈로그에 추가했다.
- 연결 테스트·스크랩 적용 오류에 포함되는 이유도 번역하며, 복구 기록·설정·후보의 오류 표시와 오류 토스트에 같은 표시 함수를 적용했다.
- HTTP 상태 코드와 예외 종류는 그대로 보존한다. 임의의 파일 경로·외부 서비스 응답은 번역하지 않는다. 오류 반환 계약이나 백엔드 처리 동작은 변경하지 않았다.
- 검증: 필수 Chromium 목업 UI 번역 검사 30개, Python 번역 검사 9개 통과. JavaScript 구문 및 diff 공백 검사 통과. 실제 WebView2/서비스와 전체 회귀는 이번 변경에서 검증하지 않았다.

### 日本語・Español・Français 지원 수준 감사
- 변경 전 최근 ID 254개에 ja/es/fr 직접 번역은 0개였으며, 각 언어에서 기존 번역 17개를 재사용할 수 있었다. 같은 한국어 문구와 같은 변수 이름일 때만 기존 번역을 ID에 연결했다.
- 언어 설정에 한국어·영어 우선 지원, 나머지 세 언어 부분 번역 및 영어 대체 안내를 추가했다. 언어 선택 항목은 유지했다.
- 변경 후 각 언어의 런타임 ID는 총 255개 중 18개 번역, 237개 영어 대체다. 이는 ID 카탈로그의 수이며 전체 앱 번역률이 아니다.
- Chromium 목업 설정 화면에서 남은 한국어 문구 수(각 언어 동일): general 18, collections 17, metadata 22, scraper 29, transfer 19, archive 23, emulator 23, appearance 18, advanced 27. 사용자 데이터는 제외했고, 탭 간 반복 문구는 포함한다. legacy 문구는 아직 한국어로 남을 수 있다.
- 세 언어의 화면 감사는 누락을 보고하며 완전 번역을 보증하는 통과 기준이 아니다. 재사용의 변수 불일치 방지, 선택 언어 유지, 지원 수준 안내를 검증한다. 선택 언어의 번역 변수가 어긋나면 정적 카탈로그 검사도 실패한다.

## UI 번역 전체 정리

- 설정·스크랩에 한정하지 않고 System 정리, Detail 미디어 메뉴, 변환, 복사/이동, 삭제, 실행 취소·복구, Revision, 충돌과 진행·완료·오류 메시지를 정리했다. ID 카탈로그 1,227개 모두 ko/en/ja/es/fr를 제공한다.
- 동적 프런트엔드 문구를 ID와 변수로 이전했다. 알려진 백엔드 문구는 정확한 템플릿으로 화면에서만 번역한다. 백엔드 오류 프로토콜과 로그 원문은 바꾸지 않았다. 경로·게임명·사용자 설명은 원문을 유지한다. 알려지지 않은 외부 진단은 임의 번역하지 않는다.
- 필수 검사에 AST 소스 감사를 추가했다. 현재 프런트엔드/HTML/백엔드 문구 1,153개에서 네 외국어의 한글 UI 누락이 없다. 로그·SQL·매칭 정규식·ROM 언어 태그는 제외한다. 새 소스 문구의 번역 누락, ID 누락 및 변수 불일치는 실패 처리한다.
- 백엔드 템플릿 전체의 네 외국어 런타임 검사와 한글 경로/미지의 오류/게임 설명 보존 검사를 추가했다. Collection 입력 안내가 객체로 출력되던 문제와 MTP 폴더명이 UI 라벨처럼 번역되던 문제도 고쳤다. MTP 이름·경로 breadcrumb는 raw 데이터로 표시한다.
- 회귀 검사의 미디어/변환 표기 기대값을 새 한국어 표기에 맞췄다. 컬럼 저장 검사는 무관한 navigation 저장과의 경쟁을 피하고 gamelist 설정 저장을 직접 확인하도록 했다. 동작 검증은 유지했다.
- 번역 범위는 앱 UI이며 게임 description 자동 번역 기능은 아니다. Chromium 목업 검사로 실제 WebView2·원어민 표현 품질·실제 NAS 및 외부 서비스 I/O를 검증했다고 주장하지 않는다.
- 최종 검증: 전체 UI 713개 통과(4.3분, 종료 코드 0), 별도 필수 번역·레이아웃·백엔드 번역 UI 71개 통과, Python 번역 검증 16개 통과. JS 구문과 diff 공백 검사 통과. 앞선 실패는 변환/미디어 라벨 기대값, Collection 안내 객체 출력, MTP 원문 표시와 컬럼 저장 경쟁으로 확인해 수정했다. 빌드·버전 증가·커밋·푸시는 수행하지 않았다.

## 스크랩 UI 모듈 분리

- app.js에 있던 스크랩 설정, 계정 연결, 사용량 표기, 멀티 스크랩 컨텍스트 622줄을 gui_web/scraper-ui.js로 옮겼다. 첫 사용 시 팩토리를 생성하고 기존 상태/DOM/API/작업 함수를 주입한다. 공유 상태의 복사나 새 전역 세션 저장소는 만들지 않았다.

- app.js 전체 분리 완료가 아니다. 붙여넣기/충돌 화면과 상태 조정은 아직 app.js에 있다. 프레임워크 변경은 하지 않았다.
- 검증: 전체 UI 713개 통과(4.1분, 종료 코드 0), 필수 번역/레이아웃 UI 71개 통과, Python 번역/API 연결 검사 21개 통과. JS 구문과 diff 공백 검사 통과. Chromium 목업 기준이며 실제 WebView2/서비스 성능 검증은 아니다. 번역 커밋 64c8bfe는 푸시했고, 이 모듈 분리 변경은 작업 트리에 남긴다.
